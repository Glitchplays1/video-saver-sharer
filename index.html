📹 Video Saver & Sharer

A family-friendly app to upload, save, and share your videos.

This is a Python Flask app — it needs a real server to run (GitHub Pages only hosts static files).

To use it:

1. Clone the repo
git clone https://github.com/Glitchplays1/video-saver-sharer.git

2. Install & run
pip install -r requirements.txt
python app.py

3. Open http://localhost:5000
